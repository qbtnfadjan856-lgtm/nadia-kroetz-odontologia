# Nadia Kroetz Odontologia

Site estático em HTML5, CSS3 e JavaScript puro, preparado para deploy na Vercel.

## Estrutura

- `index.html` — página inicial.
- `public/assets/images/` — imagens locais do site.
- `src/css/main.css` — CSS original separado.
- `src/js/main.js` — carrossel e galeria.
- `src/js/booking.js` — fluxo de agendamento.
- `vercel.json` — configuração mínima para site estático.

## Publicação na Vercel

Importe o repositório no painel da Vercel, selecione **Other** como Framework Preset e deixe Build Command vazio. Como o `index.html` está na raiz, não é necessária uma etapa de build.
